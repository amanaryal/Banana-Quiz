## Fonts, pictures, and sounds

- Headings use Fredoka and body text uses Nunito, both loaded from Google Fonts: https://fonts.google.com/

## Libraries

These were installed with npm. None of their source code is copied into this project. The app calls their public functions.

| bcrypt | Password hashing |
